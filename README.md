## Featured Research

### AI/ML Fraud Anomaly Detection — Cost-Aware & Explainable AI

**Doctoral Praxis | D.Eng. Cybersecurity Analytics | The George Washington University**

Research investigating the use of machine learning, cost-aware evaluation, anomaly detection, synthetic data, and explainable AI for financial fraud detection.

**Research components:**
- Supervised machine learning and ensemble methods
- Cost-aware threshold optimization
- Synthetic data augmentation using CTGAN
- Anomaly-feature fusion with Isolation Forest and Autoencoders
- Explainability validation using SHAP
- Model evaluation, statistical uncertainty, and reproducibility

**Key findings:**
- Cost-aware thresholding reduced expected operational loss.
- Anomaly-feature fusion improved cost efficiency in tested configurations.
- SHAP explanations showed strong real-versus-synthetic agreement.
- CTGAN augmentation did not improve performance on the evaluated dataset and split.
